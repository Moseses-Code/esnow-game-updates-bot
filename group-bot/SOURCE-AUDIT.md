# Аудит источников — 14 ноября 2026

Проверено соответствие записей Steam названиям игр, публичная ветка, текущие
ответы адаптеров, миграция старой базы и очередь уведомлений. Проверка выполнена
из Linux-среды разработки, не с рабочего Windows-ПК. Зелёный ответ HTTP не
доказывает актуальность данных, регион или полное покрытие клиента.

## Исправлено

- Fortnite: сохраняется полная версия с CL. Переключение между новостью и сборкой
  устранено. Исправления внутри 43.10 теперь различаются. Источник остаётся
  сторонним https://fortnite-api.com/v2/aes.
- LoL: убрано вычисление фиктивной версии из номера патча. При ошибке Data Dragon
  регистрируется ошибка, а последняя версия в базе сохраняется.
- Warface Astrum: удалён AppID международной Steam-версии. Используются русские
  новости https://ru.warface.com/news/; исключаются ПТС и анонсы. Это косвенный
  сигнал, а не манифест клиента. Проверен пост /news/1014276.html (5 ноября).
- Crossout: старый фильтр выбирал "New features of the November update" — обзор
  будущих изменений. Новый выбирает "Small update, October 28, 2026".
- Новости Steam: только Community Announcements, сортировка по дате, исключение
  будущих дат и типичных анонсов/тестов. Полноту понимания произвольного текста
  фильтр не гарантирует. Выпуск без новости может быть пропущен.
- Повторный переход A → B → A → B создаёт три уведомления. Прежняя уникальность
  по версии навсегда подавляла второй выпуск B. Повтор одного и того же наблюдения
  по-прежнему не создаёт уведомления.
- Смена формата источника не считается игровым обновлением. Ревизия хранится в БД.
- /sources показывает ограничения и ошибки, /status — число косвенных источников.

Классификация: 104 источника сборок/манифестов и 18 косвенных. Полный список с
оговорками находится в games.json (source_note) и доступен через /sources.
Настоящую версию установленной игры этот бот не читает.

## Ограничения доставки и времени

Опрос каждые 5 минут. Несколько изменений между опросами могут быть пропущены.
Первое наблюдение молчит. Номер сборки сам по себе не доказывает необходимость
загрузки на Windows. При потере ответа Telegram после принятия сообщения возможен
повтор: Telegram sendMessage не предоставляет ключ идемпотентности.

## Проверка на рабочем ПК

После обновления: /status, /sources, при необходимости CHECK-SOURCES.cmd.
Для дальнейшего подключения манифестов нужен доступ к соответствующим источникам
и сверка с установленными лаунчерами. Пароли и токены в переписку не передавать.
Не считать оставшиеся косвенные источники окончательно проверенным покрытием.
