ESnow — ОТКУДА И КАК ПОЛУЧАЕТСЯ ИНФОРМАЦИЯ ОБ ОБНОВЛЕНИЯХ
Дата описания: 25.11.2026.
Основание: текущие group-bot/sources.py и games.json в main репозитория Moseses-Code/esnow-game-updates-bot.
Это описание реализации, а не отчёт о доступности серверов сегодня. Версия на рабочем ПК может отличаться.

1. ОБЩИЙ ПРИНЦИП

Все сведения получаются онлайн. Бот не читает установленные игры, файлы или журналы лаунчеров на ПК администратора и не устанавливает обновления.
В списке 122 записей: 104 классифицированы кодом как сборки/манифесты, 18 — как косвенные сигналы.
Эта классификация не является гарантией достоверности: среди источников сборок есть сторонние зеркала.
«Источник ответил» означает, что адаптер получил допустимую непустую строку. Это не доказывает актуальность источника или обновление нужного клиента.
RED FLAG в текущем списке отсутствует.

2. СПРАВОЧНИК АДАПТЕРОВ

steam
Источник: SteamCMD API — сторонний сервис данных Steam.
Как извлекается сигнал: GET JSON: data[AppID].depots.branches.public.buildid. Проверяются числовой ненулевой buildid и отсутствие пароля; явно указанный статус релиза должен быть released. При отсутствии releasestate код предполагает released.
Ограничения: Смена публичной сборки не обязательно означает загрузку на Windows; зеркало может запаздывать. Для другого магазина совпадение не гарантируется.

steam_patch_news
Источник: Официальная новостная лента Steam.
Как извлекается сигнал: Из последних 100 новостей выбирается самая свежая по дате Community Announcements с подходящим заголовком патча. Будущие даты и типичные анонсы/тесты исключаются. Сигнал — gid публикации.
Ограничения: Фильтр заголовков эвристический. Тихие исправления и необычные названия публикаций могут быть пропущены.

battle
Источник: Официальный сервер версий Battle.net, EU.
Как извлекается сигнал: Таблица с разделителем |; выбирается Region=eu. Сигнал — VersionsName + ' / ' + BuildId.
Ограничения: Проверяется EU, а не установленная версия игры.

minecraft
Источник: Официальный манифест Mojang.
Как извлекается сигнал: JSON latest.release; дополнительно проверяется наличие этой версии с type=release в versions.
Ограничения: Только Java Edition и стабильный выпуск; не Bedrock и не модпаки.

albion
Источник: Официальный манифест Albion Online.
Как извлекается сигнал: XML: ./albiononline/win32/fullinstall, атрибут version.
Ограничения: Проверяется fullinstall-версия Windows; не все серверные изменения требуют смены этого поля.

roblox
Источник: Официальный сервер версий Roblox.
Как извлекается сигнал: WindowsPlayer, канал LIVE. Сигнал — version + ' / ' + clientVersionUpload.
Ограничения: Не Roblox Studio; возможен поэтапный выпуск.

osu
Источник: Официальный сервис обновлений osu!.
Как извлекается сигнал: Stable40: сортируются пары filename/file_hash, проверяется наличие osu!.exe. Сигнал — первые 16 hex-символов SHA-256 JSON списка.
Ограничения: Изменение состава или хешей меняет сигнал. Ошибка сервера вместо списка отклоняется.

fortnite_build
Источник: Fortnite-API — сторонний источник метаданных сборки.
Как извлекается сигнал: JSON data.build; допустим формат ++Fortnite+Release-<версия>-CL-<число>. Сохраняются версия и CL.
Ограничения: Это не прямой авторизованный API Epic; возможна задержка зеркала. Остальные поля ответа, включая ключи, бот не использует.

warface_news
Источник: Официальные новости русской версии Warface.
Как извлекается сигнал: HTML трёх страниц page=0,1,2. Выбираются ссылки /news/<id>.html с подходящим заголовком; берётся максимальный id. ПТС и типичные анонсы исключаются.
Ограничения: Не манифест Astrum. Время публикации отдельно не проверяется; порядок основан на id. Просматриваются только три страницы.

riot_lol
Источник: Официальный Riot Data Dragon.
Как извлекается сигнал: Первый элемент JSON списка версий, формат число.число.число.
Ограничения: Версия ресурсов не подтверждает региональную сборку клиента. Из новости версия больше не вычисляется.

riot_valorant
Источник: Valorant-API — сторонний сервис.
Как извлекается сигнал: JSON data.version.
Ограничения: Не подтверждает региональную доступность Windows-клиента.

lor_assets
Источник: Официальный CDN ресурсов Legends of Runeterra.
Как извлекается сигнал: HEAD для core, adventure, set1–set9; читаются ETag. SHA-256 объединённых через | ETag, первые 24 hex-символа.
Ограничения: Это изменение ресурсов CDN, не манифест клиента. Новые наборы после set9 автоматически не добавляются.

lesta_wiki
Источник: Официальная Lesta Wiki.
Как извлекается сигнал: MediaWiki API parse/wikitext. Регулярное выражение берёт первое подходящее обозначение версии после 'Обновление' или 'Версия'.
Ограничения: Первое совпадение не гарантирует последнюю выпущенную версию; Wiki может запаздывать или описывать будущий выпуск.

tarkov_arena_news
Источник: Официальный сайт Escape from Tarkov: Arena.
Как извлекается сигнал: HTML новостей; номера из заголовков вида Escape from Tarkov: Arena <версия> patch notes. Выбирается максимальная числовая версия.
Ограничения: Дата и завершение установки патча на боевые серверы отдельно не проверяются.

majestic_news
Источник: Публичная страница официальных Telegram-публикаций Majestic.
Как извлекается сигнал: HTML страницы majestic_gta5. Код ищет data-post с префиксом majestic/ и текстом 'Обновление:'. Сигнал — максимальный id публикации.
Ограничения: Не подтверждает именно Enhanced-клиент; зависит от HTML и имени канала; дата и смысл текста отдельно не проверяются.

genshin_news
Источник: Официальные новости HoYoLAB.
Как извлекается сигнал: GET JSON, gids=2, type=1, page_size=50. Из post.subject вида Version <номер> Update Details выбирается максимальная числовая версия.
Ограничения: Не манифест HoYoPlay; дата и завершение выпуска отдельно не проверяются, мелкие исправления без смены номера могут быть пропущены.

4. ГРАНИЦЫ ПОКРЫТИЯ

Steam-сигналы для EA App, Epic Games и BSG не доказывают одновременный выпуск в этих лаунчерах.
Call of Duty использует общий AppID HQ, поэтому не каждое изменение относится именно к Warzone.
Новости не покрывают все тихие исправления. Отсутствие новости не равнозначно отсутствию обновления.
Steam public — публичная ветка, а не универсальная гарантия статуса Stable у издателя или изменения только Windows-файлов.
Размер загрузки, необходимость установки на конкретном ПК и состояние игровых серверов эта реализация не определяет.
Для текущих ошибок используются /sources и CHECK-SOURCES.cmd. Для расписания, базы и доставки см. второй файл.
