ESnow — уведомления об изменениях версий игр
Первая рабочая версия. Не все игры списка покрыты.

Установка на Windows 10 x64
1. Создайте в @BotFather бота командой /newbot. Сохраните токен.
2. Распакуйте всю папку esnow-bot в постоянную папку, например C:\ESnowBot.
   Не запускайте программу прямо из ZIP. Не используйте общий сетевой диск.
3. Запустите SETUP.cmd. Он загрузит переносимый Python с python.org.
   Введите токен в открывшееся окно. Ввод скрыт. Токен не нужно отправлять в чат.
4. Откройте своего бота и отправьте показанную установщиком команду /start с кодом.
   Код привязывает только ваш личный чат. Установка ждёт до 10 минут.
5. Для пробного запуска откройте RUN.cmd. Через несколько минут нажмите
   «Проверить обновления» в личном чате с ботом. Закрытие окна останавливает
   ручной запуск.
6. Закройте ручной запуск и откройте AUTOSTART.cmd. Подтвердите запрос Windows.
   Будет создана задача ESnowGameUpdates, работающая от SYSTEM при загрузке
   Windows, в том числе до входа в учётную запись. Папку после этого не перемещайте.
   Задача сразу запускается. Проверьте /status и затем перезагрузку компьютера.

SETUP.cmd рассчитан на Windows 10 x64, PowerShell 5.1 и доступ в интернет.
В облачной среде проверена Python-логика; сам запуск и Планировщик Windows
здесь не проверялись. При ошибке скопируйте текст ошибки, но не токен.
Если Windows требует разрешения владельца ПК на установку задачи,
нужно получить его; отключать защиту компьютера не требуется.

Что проверяется
В конфигурации 125 установок, включая одинаковые игры в разных лаунчерах.
108 источников настроены. При проверке 12.11.2026 ответили 106.
Crossout и Deadlock не предоставили публичную сборку через используемый API.
Они отображаются в ошибках проверки, а не как игры без обновлений.
17 записей ещё не подключены; список в COVERAGE.txt и games.json.
Для Battle.net используется регион EU. Для osu! — classic stable40, не lazer.
Minecraft — только latest.release с типом release; Legacy Launcher не проверяется.

Steam проверяется через сторонний публичный сервис api.steamcmd.net.
Это не официальный API Valve; возможны кэширование, задержки и недоступность.
Проверяется buildid публичной ветки, а не beta/private.
Call of Duty: Warzone 2 сопоставлен общему приложению Call of Duty (1938090):
изменение общей сборки не обязательно означает обновление именно Warzone.
Проверка Steam-версии не покрывает отдельные обновления вложенного лаунчера.
Другие источники: официальные манифесты Battle.net, Mojang, Albion, Roblox, osu!.
Публикация версии в манифесте может предшествовать её доступности всем игрокам.
Бот не скачивает игры, не проверяет их установку и не запускает лаунчеры.

Расписание и достоверность
Часы всегда по Москве (UTC+3), независимо от часового пояса Windows.
08:30: предыдущие 20:30–08:30; 20:30: 08:30–20:30.
Сканирование каждые 15 минут, одновременно до четырёх запросов.
Период в отчёте — время обнаружения изменения, не точное время выпуска патча.
В первый обход версии запоминаются без уведомления о старых обновлениях.
Изменение buildid (включая откат) может не требовать загрузки файлов Windows.
Если игра поменялась несколько раз за смену, в сводке она указана один раз.
Неподключённые и недоступные источники перечисляются отдельно.
При выключении компьютера данные за время простоя не восстанавливаются;
бот отмечает перерыв, сравнивает версии после включения и отправляет
пропущенные сводки. Время изменений во время простоя неизвестно.

Команды в личном чате
/status — работает ли бот, количество свежих проверок.
/report — сводка с начала текущей смены; плановый отчёт она не отменяет.
«Проверить обновления» — немедленно запускает внеочередной обход, затем
присылает сводку за текущую смену. Если проверка уже идёт, второй обход
не запускается.
«Опубликовать сводку» — сразу присылает текущую сводку, не запуская проверку.
Команды из других чатов и от других пользователей игнорируются.

Файлы
settings.json — токен и ID вашего личного чата. Не публикуйте этот файл.
games.json — игры, лаунчеры и источники. Можно отредактировать и перезапустить бот.
state.sqlite3 — базовые версии, события, отчёты и очередь отправки.
bot.log — журнал без токена (ограниченный размер).
Токен и папка ограничиваются текущим пользователем, SYSTEM и администраторами.
Не удаляйте базу при обновлении программы: иначе наблюдение начнётся заново.
При сбое Telegram отчёты остаются в очереди и отправляются после восстановления.
Если Telegram принял сообщение, но ответ потерялся, повторная доставка возможна.
Одновременно может работать только один экземпляр (локальный порт 47831).
При занятом порте другим приложением бот завершится с сообщением об ошибке.

Удаление автозапуска
STOP-AUTOSTART.cmd останавливает и удаляет задачу Windows.
Ручной экземпляр RUN.cmd нужно закрыть отдельно.
После этого можно удалить папку. Другие программы не затрагиваются.

Проверка разработчиком
python -m unittest -v test_bot
13 тестов: московские границы смен, исходная версия, повторные проверки,
изменение после ошибки, Stable, публичная ветка Steam, очередь и перезапуск.
Telegram-доставка требует вашего токена и здесь не проверена.
